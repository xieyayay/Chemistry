# 怎么看技术文档网页

这份文档做成了网站，比看 Markdown 文件要方便。下面是怎么打开。

## 第一次：装工具（只需要装一次）

打开终端（Win+R → 输入 `cmd` → 回车），粘贴下面这行：

```powershell
pip install mkdocs-material
```

等它跑完就行。

## 每次想看：一行命令

终端进到项目目录 `D:\UE5\Chemistry\aa\`：

```powershell
mkdocs serve
```

然后浏览器打开 **http://127.0.0.1:8000** 就能看到了。

你改了文档内容，网页会自动刷新，不用手动 F5。看完关掉终端就行。

## 想看但不想装任何东西

已经给你提前生成好了，直接双击 `site\index.html` 用浏览器打开。

> 注意：这种方式不会自动刷新，改了文档想让内容变需要让维护者重新生成一次。

## 部署到服务器

把 `site/` 文件夹放到任意 Web 服务器上（比如公司内网的 Nginx、GitHub Pages），团队成员输入网址就能直接访问，不需要装任何东西。
