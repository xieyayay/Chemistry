# 怎么看技术文档网页

这份文档做成了网站，比看 Markdown 文件方便。下面是怎么打开。

## 最省事：双击 `本地预览.cmd`

在项目根目录 `D:\UE5\Chemistry\aa\` 下找到 **`本地预览.cmd`**，双击它。

它会自动重新构建站点、启动预览、并打开浏览器。看完直接关掉那个黑窗口就停了。

!!! note "为什么不能直接双击 `site\index.html`"

    会踩坑。MkDocs 生成的链接是「目录式」的，比如
    `animation/level-sequence/`，而磁盘上真正的文件是
    `animation/level-sequence/index.html`。**只有 HTTP 服务器会做这个映射**，
    浏览器直接打开文件时不会 —— 你点导航只会看到一个文件夹列表。

    `本地预览.cmd` 就是起了个小服务器绕开这个问题，用的是 Python 自带的功能，
    不需要额外装东西。

## 想发给别人看：双击 `生成演示版.cmd`

如果要**把网站发给别人**（比如发给服务器主人先看看效果），用这个。

它会生成一个 `site-offline\` 文件夹，里面的链接是「文件式」的，
**双击任何一个页面都能正常打开和跳转**，不需要装任何东西，也不需要起服务器。
整个文件夹压缩一下就能发出去。

!!! warning "别把这两个文件夹搞混"

    | 文件夹 | 用途 | 能不能双击看 |
    | --- | --- | --- |
    | `site\` | **放到服务器上用**，链接是目录式（`/systems/ai-task/`） | ❌ 双击只能看到文件夹列表 |
    | `site-offline\` | **发给人看 / 当面演示**，链接是文件式（`/systems/ai-task.html`） | ✅ 双击就能看 |

    两个文件夹内容一样，只有链接形式不同。**部署到服务器请用 `site\`。**

## 想看实时刷新：`mkdocs serve`

改文档时想让网页自动跟着变，用这个。打开终端（Win+R → 输入 `cmd` → 回车），
进到项目目录后运行：

```powershell
cd /d D:\UE5\Chemistry\aa
mkdocs serve
```

然后浏览器打开 **http://127.0.0.1:8000**。改完 `.md` 文件保存，网页会自动刷新，
不用手动按 F5。看完按 `Ctrl+C` 停掉。

第一次用需要先装一次工具（只需要装一次）：

```powershell
pip install mkdocs-material
```

## 部署到服务器

站点是纯静态文件，部署就是把 `site/` 目录传到服务器上。
完整步骤（含 Nginx 配置、发布与回滚流程）见项目根目录的 **`DEPLOY.md`**。
