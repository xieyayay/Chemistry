# 关卡流式加载

> 场景切换 · 三个关卡。

## 项目关卡

本项目创建了三个关卡，各自独立：

| 关卡 | 用途 |
|------|------|
| **登录界面** | 启动后第一个看到的画面，输入账号进入主菜单 |
| **主菜单** | 选择实验、进入设置 |
| **实验场景** | 具体的化学实验操作界面 |

## 怎么切换

三个关卡之间用 **Open Level** 完全切换，蓝图里一行：

```blueprint
Open Level(关卡名)
```

切换时当前关卡全部卸载，新关卡重新加载。

## 加载界面

关卡切换时会短暂黑屏或显示加载动画，相关文件在：

```
Content/JiaZai_ui/
├── WBP_F.uasset         ← 漏斗动画
├── WBP_HGX.uasset       ← 化学仪器动画
├── WBP_SYG.uasset       ← 实验仪器动画
├── WBP_ZYJ.uasset       ← 蒸馏仪器动画
└── S_ExperimentRecord.uasset  ← 实验记录结构体
```

## 关卡切换时注意

- **GameInstance** 里存的数据不会丢（全局变量、玩家信息放这里）
- **其他 Actor 会被销毁**，切回来需要重新初始化
